# Shivendra Pratap Kushwaha — portfolio

Three-page static site for [kushshiv.github.io](https://kushshiv.github.io).

- `/` Overview — 3D card stack
- `/contact` Email, LinkedIn, GitHub

Card images: drop a photo in `public/gallery/` and set `image` in `content/gallery.yaml`.

```bash
npm install
npm run dev
npm test
npm run test:e2e
```
